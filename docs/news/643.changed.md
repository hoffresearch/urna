Fewer third-party packages under the bridges and the embedded decoder (#643): `urna-av1dec` no longer depends on `parking_lot`, `atomig`, `strum`, `bitflags`, `raw-cpuid` or `zerocopy` (four small modules with the names upstream calls, every deviation listed in `rust/av1dec/UPSTREAM`, and CI compares every decoded plane with the crates.io rav1d); model, preset and benchmark-corpus downloads use the standard library (`urna.model.filefetch`: https only, size and sha256 checked) instead of `huggingface_hub`; the import contracts are checked by `tool/tasks/layerscan.py` (stdlib `ast`, now in fullcheck and CI) instead of `import-linter`; the forge's potion embedder tokenizes and embeds in Rust (`urna-neural`) through the new `urna_embedder_*` calls of the `urna-cbinds` C ABI, loaded with `ctypes` (`urna/_cabi.py`), and keeps `numpy` + `tokenizers` only as its reference where the library is absent.
