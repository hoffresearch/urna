The Launchpad PPA's source package is built from the tag (#568): `tool/tasks/ppasource.py` packs the source and every crate of `Cargo.lock` into the original tarballs, since Launchpad builds offline, and fills `pkgs/linux/apt/debian`, which compiles the CLI with Ubuntu's `cargo-1.91` and `rustc-1.91` for amd64 and arm64. The `ppaupload` job, dispatched by hand with a tag, signs and uploads it to `ppa:brennercruvinel/urna`, skipping a version the PPA already publishes; it joins the release once the PPA and its signing key exist.
