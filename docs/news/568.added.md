urna installs and updates from a Launchpad PPA on Ubuntu 22.04, 24.04 and 26.04 (#568): `sudo add-apt-repository ppa:hoffresearch/urna && sudo apt install urna`. Launchpad compiles the CLI from the release's source, with Ubuntu's `cargo-1.91` and `rustc-1.91`, for amd64 and arm64; `tool/tasks/ppasource.py` packs the source and every crate of `Cargo.lock` into the original tarballs, since Launchpad builds offline, and fills `pkgs/linux/apt/debian`. The `ppaupload` job, after the release is announced, signs and uploads it for each series, skipping a version the PPA already publishes, and a manual dispatch uploads an existing tag.
