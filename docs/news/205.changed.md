`ask`, `retrieve` and `search-text` embed a potion query in process through the new `urna-neural` runtime (its own WordPiece tokenizer and safetensors loader), with no Python interpreter on the query path. `urna doctor` reports Python as the corpus-building toolchain, a warning unless `--build`, and `urna setup` builds the Python env only with `--python` or for a chosen model.
