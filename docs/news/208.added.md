A corpus carries per-chunk columns in the new `chunk_scalars` (0x0D) section, described by the manifest's `schema`, `dataset` and `media` (all additive). `urna scalars` writes them into an existing file without changing its `content_hash`, the forge declares them as `[scalars]` and `[dataset]`, and search takes the schema's prefixes (`t:creature c:r pow>=3`) as a filter applied before scoring.
