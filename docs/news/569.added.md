urna installs and updates with apt from `urna.dev/apt` (#569): `curl -fsSL https://urna.dev/apt/urna.gpg | sudo tee /usr/share/keyrings/urna.gpg >/dev/null`, then `echo "deb [signed-by=/usr/share/keyrings/urna.gpg] https://urna.dev/apt stable main" | sudo tee /etc/apt/sources.list.d/urna.list` and `sudo apt update && sudo apt install urna`. The index lists every release's `.deb` for amd64 and arm64 and is signed by a key kept for it alone; the packages themselves stay in the GitHub releases, where a Cloudflare Worker on `urna.dev/apt` redirects. The `aptsigner` job rebuilds, signs and uploads the index after each release is announced, and a manual dispatch publishes an existing tag.
