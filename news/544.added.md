Every file names its copyright and license, machine-readable (#544, part of #547): an SPDX header in each of the 352 `.rs` and `.py` files, `REUSE.toml` for the files that carry none, listed by kind (the project's MIT, CC0-1.0 for the `demo/corpora/intro` documents, Minish Lab's MIT for the vendored potion-base-8M files), and the license texts in `LICENSES/`. The tree is REUSE 3.3 compliant; `reuse lint` runs in `fullcheck.sh` (a skip when it is not installed, never cached) and in the python job of `gatecheck.yml`. `REUSE.toml` lists neither `.rs` nor `.py`, so it fails on such a file without its header, and on a file of a kind it does not list.
