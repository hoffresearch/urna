urna installs with conda (#562): `conda install -c hoffresearch urna`, or `micromamba`/`pixi` with the same channel. The `condaship` job, after the release is announced, renders `pkgs/conda/recipe.yaml` with `pkgrender.py` and has rattler-build 0.76.1 (pinned by SHA-256) repackage the release's own binaries for linux-64, linux-aarch64, osx-64, osx-arm64 and win-64, then uploads them to the `hoffresearch` channel on anaconda.org; a version the channel already serves is skipped, and a manual dispatch publishes an existing tag.
