Homebrew installs with `brew install hoffresearch/urna/urna` in the README and the usage guide (#558). Homebrew 7.0.9 loads nothing from a tap it does not trust, so the documented `brew tap hoffresearch/urna` then `brew install urna` stopped at "Refusing to load formula hoffresearch/urna/urna from untrusted tap"; naming the formula in full trusts it.
