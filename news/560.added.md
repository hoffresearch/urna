Every release ships `.deb` and `.rpm` packages for x86_64 and aarch64 (#560): the `linuxpack` job, between the global build and the host, packs the release's static musl archives with nfpm 2.48.0 (pinned by SHA-256) from `pkgs/linux/nfpm.yaml`, installs the amd64 package on the runner and checks its version, and lists the four packages in `packages.sha256.sum`. `stampwork` stamps that file next to `sha256.sum`, so the release also carries `packages.sha256.sum.ots`. The rehearsal leaves the packing out, like the stamp.
