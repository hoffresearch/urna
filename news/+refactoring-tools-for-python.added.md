Refactoring tools for Python moves, configured in `pyproject.toml`: `[tool.pyright]` checks only that imports resolve, with the dev `sys.path` (`python/`, `python/tools/`, `script/`) as extra paths; `[tool.rope]` gives Rope the same source folders so a module move rewrites the imports in `tests/` and `python/tools/`; `[tool.importlinter]` and the `lint` dependency group add a contract that `forge` never imports `python/tools`. CONTRIBUTING has the commands.
