Every `.urna` file names the tool that wrote it (#543, part of #547): the manifest's `producer` key (`Manifest::producer()`, kept in the manifest's `extra` map so the struct and its public API do not change), `urna <version>` fixed when the bridge is compiled, so it is the same on every channel and platform and a reproducible build stays byte-identical across them. `urna inspect` shows it with the rest of the manifest, `urna validate` prints it (`-` on a file written before the field), and a file without it stays valid and byte-identical. The urna version is now one of a reproducible build's inputs, which the README and `docs/SECURITY.md` say.
