Every release gets a third-party record (#545, part of #547). Releases are immutable, so `.github/workflows/stampwork.yml`, a cargo-dist global-artifacts job that `distpatch.py` makes wait for the global build, stamps its `sha256.sum` with OpenTimestamps before the host creates the release, and the host publishes the proof with it as `sha256.sum.ots`. The client installs pinned by hash (`.github/stamplock.txt`) and runs with a read-only token; no job writes to the release but the host. If fewer than two calendars answer, the host does not run and nothing is published until the failed jobs are re-run. Once the release is announced, `.github/workflows/archiving.yml` asks Software Heritage to save the repository; a manual dispatch asks again. The rehearsal drops both, so a pull request sends nothing to the calendars. `docs/SECURITY.md` says how to verify the proof.
