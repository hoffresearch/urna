urna installs with Chocolatey (#565): `choco install urna`, once Chocolatey's moderators approve the package. The `chocoship` job, after the release is announced, renders `pkgs/choco` with `pkgrender.py` (an install script that downloads the release zip and checks its SHA-256 from `sha256.sum`, so no binary travels inside the package), packs it, installs it from that package on a Windows runner and checks `urna --version`, then pushes it to the community repository; a version the repository already holds is skipped, and a manual dispatch publishes an existing tag.
