`tool/tasks/fullcheck.sh` runs what failed in CI on #537 before a push: gatecheck's engine-only Clippy (`urna --no-default-features`), and `tool/tasks/cleanhost.sh` when the paths `cleanhost.yml` filters on changed, read from that file, in a tart macOS VM or a docker or podman Linux container; without either it prints a `SKIP` that names them, and a skipped step is never marked passed. `cleanhost.sh` builds its binary as the release it stages (`URNA_RELEASE_TAG`). CONTRIBUTING has a "Local gate" section with the tools and how to install them.
