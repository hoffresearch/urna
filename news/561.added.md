urna installs with dnf from COPR (#561): `dnf copr enable hoffresearch/urna`, then `dnf install urna`, on Fedora and EPEL. The `coprbuild` job, after the release is announced, renders `pkgs/linux/dnf/urna.spec` with `pkgrender.py`, checks the two musl archives against `sha256.sum`, builds the source rpm and has COPR build it with copr-cli 2.6 (pinned by hash in `.github/coprtools.txt`); the spec repackages the release's own static binary, so dnf installs the same bytes as every other channel. A version COPR already built is skipped, and a manual dispatch publishes an existing tag.
