The sentence-transformers backend routes a role the way the model takes it (#534): a model that picks its adapter by `task` (jina v5) gets the role as its prompt, as jina's omni code makes `encode_query` do, instead of `encode_query`'s `task="query"` over its own; a preset can name its query prompt (`harrier-270m`: `web_search_query`) and its MPS dtype (`harrier-270m` loads in bfloat16, float16 makes every vector NaN). The preset packages cap `sentence-transformers` below 6, whose `Normalize` refuses Octen's config. `clip-vit-b32` loads from a pinned snapshot of `timm/vit_base_patch32_clip_224.openai`, the repo open_clip resolves its tag to, with the same `model_hash`. The python range and the torch sizes come from the torch the lock resolves to. The validated installs and the reviewed code pins moved to `urna/model/installed.py`, the catalogue types and estimates of the setup to `tui/setup/catalog.rs`.
