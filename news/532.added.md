`urna tui` opens where a user left off (#532, part of #535): the file it is given, else the corpus it opened last, from any directory, on the ask tab, else a first-run screen with two actions, open the sample corpus (`enter`, one more `enter` asks it) or open a `.urna` (`o`). A last corpus deleted or moved since lands on the first-run screen, not an error. Back from `s` with the sample just downloaded, it opens the sample on the ask tab. The corpora it opened, at most nine, resolved so one file is one entry from any directory, are kept in `<data root>/urna/tui.json`, written whole or not at all; an unreadable file is a first run, and `urna setup --uninstall` removes it.
