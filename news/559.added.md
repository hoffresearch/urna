Each package channel's manifest is rendered from the release (#559): `tool/tasks/pkgrender.py` fills the templates in `pkgs/` (scoop, winget, conda, Chocolatey, the COPR spec, and one nfpm config per Linux architecture) from the release's `dist-manifest.json` and `sha256.sum` and from `[workspace.metadata.pkgs]` in `Cargo.toml`, with no version or hash typed by hand: every URL must be under the release's tag, each text is escaped for the file it lands in, and a channel is written whole or not at all. The empty AUR placeholder is gone, since the AUR is not accepting new accounts.
