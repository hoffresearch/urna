Every unreleased change is a file in `news/` (#556): `<issue>.<type>.md`, one line written as its changelog entry, with the Keep a Changelog types of `pyproject.toml`'s `[tool.towncrier]`, so no two pull requests edit the same line of `docs/CHANGELOG`. `tool/tasks/releasepr.sh` runs towncrier 26.9.0 (`uv tool install towncrier==26.9.0`), which writes them as the release's dated section below the marker and removes them; cargo-release now only dates the changelog and `CITATION.cff`. `preflight.py` refuses an entry under `[Unreleased]` and a fragment towncrier would not read. The `opensource` ruleset no longer requires a branch up to date with `main`: with no changelog conflict, that only cost one more CI run per pull request.
