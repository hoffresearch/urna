urna runs with nix (#566): `nix run github:hoffresearch/urna -- --version`, or `nix profile install github:hoffresearch/urna`. `flake.nix` at the root builds the CLI from source through `pkgs/nixos/package.nix` (`buildRustPackage` with `Cargo.lock`, the version and summary read from `Cargo.toml`), leaving out the git-lfs model and the separate ingest workspace, so the binary is a release build and `urna setup` fetches that release's payload. The `nixosship` job, after the release is announced, runs the tag's flake on Linux and checks its version.
