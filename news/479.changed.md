The repository moved to seven four-letter root folders and one Python package (#479, part of #296; ADR-0003 supersedes ADR-0002). `crates/` is `rust/`, `script/` is `tool/tasks/`, `tests/` is `tool/tests/`, the benchmarks of `python/tools/` are `tool/bench/`, `packs/` is `pkgs/wheel/` (the wheel stages into `pkgs/stage/`), `demos/` is `demo/` (`quickstart` is `starter`, `flask` is `flaskpy`), `assets/` is `docs/img/`, `docs/ADR` is `docs/adr` with lowercase categories, `docs/ARC.toml` is `docs/ARCHS.toml`. `python/` and `python/forge/` dissolve into the `urna` package at `rust/bridge/python/urna/`, with the subpackages `embed`, `entry`, `gates`, `image`, `model`, `pipes`, `reads` and `specs` and nine-letter modules; the forge's self-tests join `tool/tests/`, the demo corpus is `demo/corpora/intro/`, and the potion table is `urna/model/potionb8m/` (the model id stays `minishlab/potion-base-8M`). What users see in the next release: the embedder payload installs under `<data root>/urna/python/urna/`, so an existing install needs `urna setup` again, which lays the new payload down and removes the previous one (`forge/`, `embed_query.py`, `model_fingerprint.py` and their `__pycache__/` in the data dir); `urna setup --uninstall` and the one-liner installers remove them too. The one-liner installer moves to `tool/tasks/installer.sh` (and `.ps1`) and `script/` is gone, so the `script/installer.sh` URL the 0.5.4 pages print answers 404 until the next release replaces them. The wheel follows the package: `urna.embed_potion` is `urna.embed.potiontab`, its table is `urna/model/potionb8m/`, and the console script runs `urna.entry.clidriver`. `import urna` no longer loads the `_urna` extension: it loads on the first `urna.open`, `urna.UrnaFile` or `urna.build`, so the query embedders import the package in the payload, which carries no extension. No format or runtime change.
