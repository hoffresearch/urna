One set of package texts for every channel (#558): `[workspace.metadata.pkgs]` in `Cargo.toml` holds a summary of at most 80 characters, a one-paragraph description with an example and the search tags, in plain text, and `preflight.py` refuses a PyPI description that opens unlike the crate's and a summary past 80 characters. Recorded demos, linked by absolute URL so they render on crates.io, PyPI and npm: `urna build` and `urna ask` with its citation on the starter corpus and the install through Homebrew and npm in the README, `cargo binstall` and `uv tool install` in the usage guide.
